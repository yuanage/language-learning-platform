# 墨流字河 · Glyph Currents

## 算法哲学

**墨流字河（Glyph Currents）** 是一场关于"语言即流体"的计算美学运动。文字不是静止的符号，而是被无形洋流托举的墨滴——它们从深层噪声场中获得方向，彼此擦肩、汇聚、消散，又在下游重新凝结成可辨识的字符。整个系统是对"多语种学习"这一行为的抽象转译：三种文字（拉丁、假名、谚文）同处一条长河，彼此独立又互相致意。

在计算层面，长河由**多层叠加的 simplex 噪声场**驱动。三层数学噪声以不同频率与步长叠加：最粗的一层决定河道的主走向，中间层制造涡旋与回流，最细的一层赋予每个粒子细微的颤动——如同墨滴入水时边缘的震颤。粒子不遵循路径，它们只是**采样场、顺流而行**；所谓"河道"，不过是千万次采样之后自然显形的轨迹密度。没有任何粒子知道整条河的形状，形状是涌现的。

字符本身是**漂浮的墨模（glyph sprites）**。每个粒子携带一个字符——`A`、`あ`、`가`——以及由种子决定的字号、透明度与色相偏移。字符沿场漂流时缓慢旋转，透明度随其在噪声场中的"深度"呼吸式起伏：靠近场谷值的字符清晰浮现，靠近峰值的字符沉入背景化为淡影。远景与近景由此生成——不是靠透视矩阵，而是靠**噪声深度**，这是本哲学区别于普通粒子系统的核心笔触。

**时间演化**遵循"墨入清水"的扩散律：画布永不完全重绘，而是以极低透明度的底色缓慢覆盖，让旧墨迹退为薄雾，新字符在其上继续书写。系统在数分钟后达到视觉均衡——历史与当下共存于同一画布，如同学习者脑中累积的词汇。这一切参数——噪声倍频比、墨迹存留率、字符密度、三种文字的出现概率——都经过反复推敲与精调，唯有如此，随机性才能呈现出"看似偶然、实则必然"的秩序之美。

**色彩**上，墨流字河拒绝随机 RGB。亮色模式下，长河流经"宣纸白"（#faf9f5）的静谧底色，字符以靛青（#5b7cfa，主色）、珊瑚（#d97757）与青瓷（#788c5d）三色区分语种；深色模式下，底色沉为"墨夜"（#0d1020），字符化为发光的浮墨，色相同步降低明度、提高饱和，如同夜航时舷侧的荧光。**同一种子，双生风景**——亮暗两版来自同一组参数，只是光照不同，这是长河对昼夜的回应。

## 概念种子（Conceptual DNA）

三种文字粒子以近乎相等却略有涨落的概率出现——占比由噪声缓变而非固定配比——暗合平台"英·日·韩"三语并行的基因。只有熟悉这三种文字的人会在流水中认出 `A`、`あ` 与 `가` 的交替浮现；其他人看到的，是一条美得恰到好处的墨色长河。

## 参数空间

| 参数 | 含义 |
|---|---|
| seed | 随机种子，唯一决定整条河的形态 |
| particleCount | 河中字符墨滴数量 |
| flowSpeed | 洋流速度 |
| noiseScale | 噪声场尺度（河道弯曲度） |
| fadeAlpha | 墨迹存留率（画布覆底透明度，越小历史越长） |
| glyphSize | 字符基准字号 |
| scriptBias | 三文字概率的涨落幅度 |

## 落地形态

1. **交互式查看器**（`design/art-viewer.html`）：完整 p5.js 实现，可探索种子与参数空间，下载 PNG。
2. **应用内嵌背景**（`client/src/components/GenerativeBackground.jsx`）：同一哲学的零依赖 Canvas 精简实现——低密度、慢速、克制的透明度，作为登录/注册页的氛围底画；尊重 `prefers-reduced-motion`（静帧降级）与页面隐藏时暂停。
